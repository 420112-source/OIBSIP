# Level 3 - Responsive E-Commerce Website

## Overview
This is a full-stack responsive e-commerce web application developed for the Oasis Infobyte Web Development & Designing Internship.

## Features
- Responsive product grid layout
- Category filter and live product search
- Dynamic shopping cart drawer with price calculation
- Modern UI/UX styling

## Tech Stack
- HTML5, CSS3, JavaScript (ES6)
- FontAwesome Icons
